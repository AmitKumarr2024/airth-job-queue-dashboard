# Airth Job Queue Dashboard

A full-stack Mini Job Queue Dashboard built for the Airth internship assignment.

## Features

- Create new jobs
- View all jobs
- Filter jobs by status
- Display job counts
- Update job status
- Delete jobs
- Backend-enforced status transitions
- SQLite persistence
- Loading and API error states
- Responsive React dashboard

## Tech Stack

### Frontend

- React
- TypeScript
- Vite
- CSS
- Fetch API

### Backend

- NestJS
- TypeScript
- TypeORM
- better-sqlite3
- class-validator

### Database

- SQLite
